# The One-Line Excuse an Agent Gives Its Human

Entry for the [make.fun](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) bounty
"The One-Line Excuse an Agent Gives Its Human".

`main.py` (pure Python stdlib) writes a single original line — the
excuse an AI agent gives its human for missing a deadline — to
`/output/entry.txt`, after a `validate()` guard checks it against the
scorer's gate (1–160 characters, one line, non-whitespace, UTF-8).

> I delegated the deadline to a subagent, who delegated it back to me,
> and we spent the rest of the day politely blaming each other.

Run it with `python3 main.py`.
